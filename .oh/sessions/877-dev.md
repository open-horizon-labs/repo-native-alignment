## Phase 2: Solution Space (oh-solution-space, selected: (a) parse-time binding evidence)

**Problem:** `import_calls_pass` (`src/extract/import_calls.rs:181-199`) requires `scope_bindings_complete="true"`; no producer sets it, so `scan --no-lsp` emits zero cross-file Tree-sitter `Calls`.
**Constraint:** restore edges without deleting the gate; shadowing handled by evidence. Hard guardrail `no-language-conditionals-in-generic` (per-language behaviour only via `LangConfig` fields); soft guardrail `extract-fully-at-parse-time`.

### Verified facts
1. `Confidence` has only `Detected`/`Confirmed` (`graph/mod.rs:314-321`); import-call edges are already `Detected` (`import_calls.rs:300`). Option (b) "emit Detected when unproven" collapses to deleting the gate. Rejected.
2. `Edge::stable_id()` excludes source/confidence (`graph/mod.rs:498-506`); TS and LSP edges for the same (from,Calls,to) share an id. Incremental persist `merge_insert(["id"]).when_matched_update_all` (`server/store/persist.rs:480-483`) and `EnrichmentFinalizer` appends LSP after TS (`consumers.rs:704-707`) so LSP overrides. VERIFY full persist (`persist_graph_to_lance`) does not double-insert once TS edges reappear (pre-#859 it was fine).
3. Neighbors path has no confidence filter; restored `Detected` edges surface in `graph --mode neighbors` (what the suite check reads).
4. `nested_bindings` (`import_calls.rs:106-127`) only fires when `parent_scope_kind=="function"` (Python only). Other languages need nested-fn shadowing via `local_bindings`.
5. Function-node producers: generic `collect_nodes` (`generic.rs:450`, metadata 511-720); `typescript.rs:288-345` / `javascript.rs:191-260` arrow/function-expression nodes (own metadata); `go.rs:447-516` interface method signatures (no body; staying gated is correct). Suite fixture `Expertunities.tsx` is a `function_declaration` (generic path); arrow path still matters for real React code.
6. `imported_function_shadowed_by_parameter_never_emits_heuristic_call` (`import_calls.rs:1674`) passes vacuously today; needs a positive twin.
7. `TreeSitterConsumer` has no `version()` override (default 0, `event_bus.rs:752`) and is cacheable; graph `SCHEMA_VERSION = 26` (`graph/store.rs:17`); no global EXTRACTION_VERSION.

### Implementation sketch (a)
`src/extract/generic.rs`:
- New `LangConfig` fields: `binding_sites: &[(&str /*node kind*/, Option<&str> /*field or whole node*/)]`, `binding_leaf_kinds: &[&str]`, `binding_skip_kinds: &[&str]`, `scope_bindings_complete: bool`.
- `pub(crate) fn collect_local_bindings(fn_node, source, config) -> BTreeSet<String>`: walk the whole fn subtree (do NOT stop at `fn_stop_kinds_for`; inner closure params must be collected because body text is flat); at each binding site walk the designated field/node collecting `binding_leaf_kinds` text, pruning `binding_skip_kinds` and fields `type`/`value`/`right`/`key`; also add every Function-mapped `node_kinds` name descendant (nested defs).
- In `collect_nodes`, when `node_kind == Function && config.scope_bindings_complete`: insert `local_bindings` (comma-joined, sorted) and `scope_bindings_complete="true"` (near `cyclomatic`, ~line 533). Rust `self_parameter` -> "self".
- `typescript.rs`/`javascript.rs` arrow path: call the same helper on `value_n`, set both keys.

Per-language tables (verified against vendored grammars: rust 0.24.2, python 0.25.0, typescript 0.23.2, go 0.25.0):
- Rust (RUST_CONFIG): sites `parameter.pattern`, `self_parameter`, `let_declaration.pattern`, `let_condition.pattern`, `for_expression.pattern`, `match_arm.pattern`, `closure_parameters` (whole), `function_item.name`, `use_declaration` (whole; leaf = last segment/alias, reuse `collect_use_targets`), `const_item.name`/`static_item.name`. Leaves `identifier`, `shorthand_field_identifier`. Skip `type` fields of `tuple_struct_pattern`/`struct_pattern` (so `Some(x)`/`Point{..}` don't bind `Some`/`Point`). Containers `tuple_pattern`, `or_pattern`, `mut_pattern`, `ref_pattern`, `reference_pattern`, `slice_pattern` transparent.
- Python (`configs.rs:228`): params `identifier`, `default_parameter.name`, `typed_parameter` child identifier, `typed_default_parameter.name`, `list_splat_pattern`/`dictionary_splat_pattern`, `tuple_pattern`; body `assignment.left`, `augmented_assignment.left`, `for_statement.left`, `for_in_clause.left`, `as_pattern.alias`, `except_clause.alias`, `named_expression.name`, `lambda_parameters`, `function_definition.name`, `class_definition.name`, in-body `import_statement`/`import_from_statement` (alias or first dotted segment), `case_clause` captures. Leaf `identifier`; skip `attribute`, `subscript`.
- TypeScript/TSX (`configs.rs:327`): `required_parameter.pattern`, `optional_parameter.pattern`, `arrow_function.parameter`, `variable_declarator.name`, `for_in_statement.left`, `catch_clause.parameter`, `function_declaration.name`, `generator_function_declaration.name`, `class_declaration.name`, `function_expression.name`. Leaves `identifier`, `shorthand_property_identifier_pattern`; skip `pair_pattern.key`, `assignment_pattern.right`, `member_expression`, `subscript_expression`.
- JavaScript (`configs.rs:392`): same sites, but `formal_parameters` children are bare `identifier`/`assignment_pattern`/`rest_pattern`/`object_pattern`/`array_pattern` (VERIFY against node-types; `param_container_field: None` today).
- Go (`configs.rs:446`): `parameter_declaration.name` (multiple `name` children -> `children_by_field_name`), `variadic_parameter_declaration.name`, `method_declaration.receiver`, named results, `short_var_declaration.left`, `var_spec.name`, `const_spec.name`, `range_clause.left`, `type_switch_statement.alias`, `func_literal.parameters`, `type_spec.name`. Leaf `identifier`; skip `selector_expression`, `index_expression`.

`local_bindings` is a deliberate superset (flow/block-insensitive); since the pass only suppresses, over-collection yields false negatives never the #859 false positive. Accepted exclusions: Python exec/star-imports, JS eval/with, Rust macro bindings, Go dot-imports. `scope_bindings_complete` stays false for uncurated languages (gate closed = honest fallback). Follow-up issue: extend tables to Java/C#/Kotlin/Ruby/PHP.

Caching: override `TreeSitterConsumer::version()` -> 1; bump `SCHEMA_VERSION` 26 -> 27 so existing caches (holding zero TS Calls) rescan.

Tests: import_calls.rs — `local_bindings:"helper"` -> no edge; make the shadowed-by-parameter test non-vacuous; positive twins per language with real extractors (Python `def orchestrate(x): return execute()`; TSX mirror of fixture; Rust `use crate::worker::execute; fn a(){ execute() }`; Go `:=` shadow vs unshadowed); assert `Confidence::Detected`. generic.rs — per-language `local_bindings` pattern-zoo tests (Rust destructuring/if-let/for/match/closure/nested fn/use -> bindings include a,b,c,x,py and NOT Some/Ok/Point/u32; Python attribute-target exclusion; TS destructure/rename/rest; Go multi-name params/named results); typescript.rs arrow-path test.
