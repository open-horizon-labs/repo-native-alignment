# Issue 786: Combined semantic and LSP cache artifact

## Aim

Ship one exact CI-built Apple M4/Metal RNA artifact that performs mandatory
Pyrefly LSP plus embeddings and reranking, proves a verifier-clean cold to
incremental combined-cache pair, and begins the unchanged frozen N=70 cache
chain without paid API or benchmark execution.

## Problem Statement

The existing semantic table cannot safely cross repository trees because it
mutates visible rows in place, carries insufficient semantic identity, and
treats table queryability as readiness. The target structural graph must be
authoritative, while semantic reuse must be exact, atomic, and independently
verifiable after reopen.

## Solution Space

Use repo-local immutable embedding generations with an atomically published
current pointer. Rebuild target scalar metadata and FTS state from the reopened
target graph, reuse only exactly identity-matched vector payloads, and publish
only after one-to-one coverage validation. Bind the verified #785 structural
archive and semantic generation in a separate deterministic combined-cache
manifest. Qualification uses only the successful exact-head CI M4/Metal
artifact and fails closed on every fallback or identity mismatch.

## Execute

**Status:** implementation batch stable; exact-head CI artifact pending

- Draft PR: #806
- Branch: issue/786
- No real corpus, LSP, embedding, rerank, model, paid API, or benchmark call
  occurs before the exact artifact and verifier gates.
- Combined qualification rejects `--no-embed`, requires one persisted
  `embeddings: ran` phase, and records inherited, encoded, and purged vector
  work independently of structural reuse.
- Vector payload reuse is now keyed by exact encoder text plus the complete
  semantic identity, independently of target row identity and scalar metadata.
  Persistence-only document-symbol proof nodes remain in the structural graph
  but are excluded from semantic candidates; schema-v1 combined caches reject
  without extraction or mutation.
- Default and embedding/Metal compile gates, focused Rust semantic tests, 13
  Python cache/verifier tests, and the single full default suite are green:
  2,218 library tests plus every integration target, including the real cache
  chain. Local verification did not load a model or execute a repository scan.
